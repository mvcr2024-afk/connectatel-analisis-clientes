# Análisis de Clientes - ConnectaTel

## Objetivo
Analizar el comportamiento de uso y las características de los clientes de ConnectaTel para identificar patrones, segmentos y oportunidades comerciales.

## Datasets utilizados
- plans.csv
- users_latam.csv
- usage.csv

## Etapas del análisis
1. Carga y exploración inicial de los datos
2. Revisión y limpieza de valores nulos y sentinels
3. Corrección de fechas imposibles
4. Agregación de métricas de uso por usuario
5. Detección de outliers (boxplots e IQR)
6. Segmentación de clientes por uso y edad
7. Visualización de distribuciones
8. Conclusiones e insights ejecutivos

## Cómo ejecutar el notebook
1. Abre el archivo .ipynb en Google Colab o Jupyter Notebook.
2. Asegúrate de tener instaladas las librerías: pandas, matplotlib, seaborn.
3. Ejecuta las celdas en orden, de arriba a abajo.

## Guía de reproducción
Todo el análisis es reproducible ejecutando el notebook completo con Run All Cells, siempre que los archivos CSV estén disponibles en la ruta especificada.# connectatel-analisis-clientes
